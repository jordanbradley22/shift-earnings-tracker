# shift-earnings-tracker
A Python command-line application for tracking work hours, earnings, and weekly income goals.

## Purpose 
I am building this project to practice Python fundamentals while creating a tool that is useful in my own working life. The program will help users compare income from different jobs and understand their weekly earnings. 

## Planned Features
* Record the date, job, hours worked, and earnings
* Calculate average hourly earnings
* Display total weekly hours and income
* Compare earnings with a weekly income goal
* Reject missing or invalid entries
* Save entries so they can be viewed later

## Version 1 Roadmap
1. Collect information for one work shift
2.  Display a summary of the shift
3. Calculate the hourly earnings
4. Accept and validate multiple entires
5. Calculate weekly totals
6. Save and reload earnings data
7. Add tests and complete the documentation
